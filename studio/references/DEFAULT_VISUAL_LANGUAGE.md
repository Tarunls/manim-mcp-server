# Default visual language

The studio's default is a cinematic editorial educational-video style distilled from two successful Composite lessons. The source lessons are references for visual judgment, not reusable teaching content.

Review both reference sets before planning a first draft:

- `fourier-house-style/frames/` demonstrates fluid mathematical motion, staged reveals, restrained color, and a clear division between Manim inserts and Remotion composition.
- `integral-house-style/integral-reference.mp4` demonstrates the complete pacing and transition rhythm of a strong four-beat lesson. Its selected frames are in `integral-house-style/frames/`.

Preserve the shared visual grammar:

- Build about four chapter-like beats over 35-45 seconds unless the user requests another duration.
- Anchor each beat with a short chapter eyebrow and one bold teaching claim.
- Use at most one restrained explanation card; supporting copy must never compete with the main visual.
- Give one large visual stage ownership of the frame. Mathematical motion is the centerpiece, not decoration.
- Use dark cinematic depth, subtle gradients, thin borders, warm off-white type, and one or two semantic accent colors.
- Keep generous negative space, consistent alignment, and a stable hierarchy. Avoid dashboards, grids of cards, and excessive simultaneous labels.
- Let Manim create mathematical or geometric motion. Let Remotion own final composition, typography, narration timing, transitions, and polish.
- Make each beat visibly transform the idea instead of merely replacing text.

Do not copy a reference lesson's subject, words, equations, narration, or graphics into a different topic. Re-plan the pedagogy from scratch. A repeated prompt is still a new production when the turn identifies itself as a first draft.
