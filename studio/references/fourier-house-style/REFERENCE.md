# Fourier house style

These frames come from the studio's strongest early Composite lesson. They are a visual quality reference, not reusable teaching content.

Preserve this visual grammar in a new lesson:

- Four chapter-like beats over roughly 35–45 seconds unless the user requests another duration.
- A short chapter eyebrow and a bold two-line teaching claim anchor the left side.
- A single restrained explanation card supports the claim; it never competes with the main visual.
- One large visual stage owns the right side. Mathematical motion is the centerpiece, not decoration.
- Dark cinematic depth, subtle gradients, thin borders, warm off-white type, and one or two semantic accent colors.
- Generous negative space and consistent alignment. Avoid dashboards, grids of cards, and excessive simultaneous labels.
- Manim creates the mathematical or geometric insert. Remotion owns the final composition, typography, narration timing, transitions, and polish.
- Each beat transforms or replaces the dominant visual so the viewer can feel the conceptual progression.

Do not preserve Fourier-specific words, equations, waveforms, spectra, narration, or code when the user asks for another topic. Re-plan the pedagogy from scratch and rebuild every subject-specific visual. A repeated prompt is still a new production when the turn identifies itself as a first draft.
